Un paquet .deb pour Debian et Ubuntu, testé sur Ubuntu 24.04. Gratuit, pour tout le monde.

Dernière version

CloneGator

Télécharger le .deb

Ou dans un terminal

wget github.com/kevin-belanger/CloneGator/releases/latest/download/clonegator.deb
sudo apt install ./clonegator.deb
sudo clonegator

Pour mettre à jour, les mêmes commandes : apt remplace l'ancienne version et garde vos réglages. Pour désinstaller : sudo apt remove clonegator.
